# Geomagnetic Solar Telemetry & ISS Tracking Interface

**Live Web Dashboard:** astropulse-9tm30vetj-japman-singh-s-lab.vercel.app

## Architecture & Physics
This application queries NASA's DONKI API to parse real-time geomagnetic telemetry using asynchronous JavaScript. It translates raw JSON payloads into physical realities, specifically tracking the macroscopic demonstration of the Lorentz Force ($F = q(v \times B)$) as solar plasma interacts with Earth's magnetic field. 

The system also executes the Haversine formula for spherical spatial distance calculations to track the ISS relative to the user's coordinates.
